eduLIMS is "an open-source laboratory information management system (LIMS)
for practical laboratory education". The repository, the docs site, issues,
PRs and UI copy name no people and no institution, research group, course or
coursework. The only name is the maintainer's, where licensing and
maintenance require it: SPDX headers, `LICENSE`, `NOTICE`, `CITATION.cff`,
`MAINTAINERS.md`, `CODEOWNERS`. Roles in prose are "the maintainer", "the
product owner", "the institution".

**Why:** the owner, 2026-11-11: "there is way too much information about the
institution and names of people … make it more generic and more
professional". Git history from before that cleanup still holds them; it is
not rewritten.

**How to apply:** write neutral, professional English; the lab domain (the
analysers, openEHR, HL7 v2, FerroEHR, FerroBRIDGE) stays, since it is the
product. See [[spdx-and-languages]].
