If you use eduLIMS in research or teaching that you publish, cite the
software. The citation metadata lives in
[`CITATION.cff`](https://github.com/Vernum-Projecten/eduLIMS/blob/main/CITATION.cff)
in the repository, in the [Citation File Format](https://citation-file-format.github.io/).

## From GitHub

The [repository page](https://github.com/Vernum-Projecten/eduLIMS) shows a
**Cite this repository** button in its sidebar. GitHub builds it from
`CITATION.cff` and offers the citation as APA text and as BibTeX, ready to
copy into your reference list.

## With a DOI

Every eduLIMS release is archived on [Zenodo](https://zenodo.org/), which
gives each release its own DOI and the project one concept DOI that always
resolves to the newest release. Cite the version DOI when your work depends on
the behaviour of one release, and the concept DOI when you refer to eduLIMS in
general. How a release reaches Zenodo is in
[Cutting a release](/development/release/#citation-and-zenodo).
