## What it does

<CardGrid>
  <Card title="Samples with a traceable ID" icon="seti:db">
    Students register samples and get a unique sample ID, so every
    measurement traces back to the analyser, the sample and the student.
  </Card>
  <Card title="Results straight from the analysers" icon="random">
    HL7 v2 results arrive through FerroBRIDGE, and plate-reader exports are
    validated on upload. Measurements are stored as openEHR compositions in
    FerroEHR.
  </Card>
  <Card title="Grading with a rubric" icon="approve-check">
    Teachers set up a practical with an assignment, a protocol, a deadline
    and a rubric, grade each lab report per criterion, and follow their
    classes on a KPI dashboard.
  </Card>
  <Card title="Sign-in and roles you control" icon="seti:lock">
    Users sign in with Microsoft Entra ID or Keycloak through OpenID Connect.
    Roles come from the identity provider, and every server function checks
    role and ownership.
  </Card>
  <Card title="Signed releases" icon="seti:shell">
    Container images on GHCR with SLSA Build Level 3 provenance and signed
    SBOMs, deployed with Docker Compose on one Linux host.
  </Card>
  <Card title="Open source" icon="open-book">
    Apache License 2.0. The requirements, architecture and decisions are
    published with the code.
  </Card>
</CardGrid>
