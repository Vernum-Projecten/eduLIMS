## What it does

<CardGrid>
  <Card title="Patients, requests and samples" icon="seti:db">
    Each team of students runs a lab, under the lab name and the logo the
    team made up. The team registers patients and requests from paper forms
    and links each sample by the sample number on the form. Every measurement
    traces back to the analyser, the sample, the patient and the lab.
  </Card>
  <Card title="Results straight from the analysers" icon="random">
    HL7 v2 results arrive through FerroBRIDGE, and plate-reader exports are
    read on upload. A lab releases each result to the patient's record,
    stored as an openEHR composition in FerroEHR.
  </Card>
  <Card title="A live dashboard for teachers" icon="approve-check">
    Teachers enter the correct values of a simulation beforehand and follow
    every lab live: the time per request, every measurement, and the accuracy of
    each released result. There is no grading.
  </Card>
  <Card title="Sign-in and roles you control" icon="seti:lock">
    Users sign in with Microsoft Entra ID or Keycloak through OpenID Connect.
    Roles come from the identity provider, and every server function checks
    role and ownership.
  </Card>
  <Card title="Signed releases" icon="seti:shell">
    Container images on GHCR with SLSA Build Level 3 provenance and signed
    SBOMs, deployed with Docker Compose on one Linux host.
  </Card>
  <Card title="Open source" icon="open-book">
    Apache License 2.0. The requirements, architecture and decisions are
    published with the code.
  </Card>
</CardGrid>
