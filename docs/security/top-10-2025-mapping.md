# OWASP Top 10:2025 mapping

How eduLIMS answers each category of the OWASP Top 10:2025. The category
text is vendored in [vendor/top10/](vendor/top10/); the ASVS ids point into
the [applicability table](asvs-5.0-applicability.md), which holds the status
of each one; the cheat sheets are in [vendor/cheatsheets/](vendor/cheatsheets/).
Q-SEC-1 asks for an OWASP Top 10 check that finds no endpoint open without
sign-in: this page is the checklist that check works through.

| Category | eduLIMS today | Still to do | ASVS | Cheat sheets |
|---|---|---|---|---|
| [A01 Broken Access Control](vendor/top10/A01_2025-Broken_Access_Control.md) | `authMiddleware` and `requireRole` on every server function (`src/server/middleware.ts`); role sets validated on every write (`src/server/role-guard.ts`, ADR 0012); post-login redirects kept on the origin (`safeRedirectPath`, #29); FerroEHR and FerroBRIDGE URLs from configuration only (SSRF) | ownership in the SQL of every S7 and D3 query; class membership checks (#28); a role-isolation test per server function | V8.1 to V8.4, V3.7.2, V1.3.6, V15.3.3 | Authorization, Access_Control, Insecure_Direct_Object_Reference_Prevention, Multi_Tenant_Security, Server_Side_Request_Forgery_Prevention, Unvalidated_Redirects_and_Forwards, Authorization_Testing_Automation |
