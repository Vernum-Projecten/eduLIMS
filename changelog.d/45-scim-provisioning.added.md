Identity providers can provision and deprovision users over SCIM 2.0 (B1): administrators see provisioned users before their first sign-in, roles follow the provider's role map, and a user the directory deactivates loses every session at once and cannot sign in, while their records stay. Create, replace and revoke each provider's SCIM token on its page in Admin → System → Identity providers or with `scim token` from the tools image: a token works for 180 days, the page warns 14 days before it expires, and a replaced token keeps working for one hour; the database migration `0013_scim` runs with the usual migrate step. Set `EDULIMS_TRUSTED_PROXIES` to the reverse proxy's address so the SCIM rate limit can tell clients apart; left empty, no forwarded header is trusted.
