- Only one simulation runs at a time. Starting a simulation while another one runs is refused with a message that names no other simulation, and the overview of a prepared simulation says so before you press Start. Prepared and finished simulations stay next to the running one. The teacher dashboard says when no simulation runs, or when the running one is not yours, and links to your simulations. Upgrade step: an installation with two or more running simulations fails the migration; finish all but one before you upgrade.
