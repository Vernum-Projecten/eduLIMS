- Identity providers are no longer configured in `.env`: `MICROSOFT_*`, `KEYCLOAK_ISSUER`, `KEYCLOAK_CLIENT_ID`, `KEYCLOAK_CLIENT_SECRET`, `KEYCLOAK_LABEL`, `OIDC_ROLE_CLAIM`, `OIDC_ROLE_MAP` and `OIDC_DEFAULT_ROLE` are gone. Upgrade step: set the new required `EDULIMS_DATA_KEY` (`openssl rand -base64 32`), then add the first provider with `docker compose run --rm edulims-tools idp add` (docs/deployment.md, "First start").
