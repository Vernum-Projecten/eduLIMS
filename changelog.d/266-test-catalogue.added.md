- Teachers manage the test catalogue in the Teacher portal: add a test with its name, unit
  and material, set where its measurements come from (the Afinion 2 with the analyte name it
  sends, the Epoch 2 upload with who calculates the concentration, or entry by hand), edit it,
  and retire or restore it. Every change is in the activity log with ids only (D9, S4). The
  database migration `0016_test_catalogue` runs on the next start.
